Quick answers

Using Treasure Log

These answers describe the current app behavior. Screen labels may vary slightly by release.

01How do I add or update a holding?

Open Holdings or use Add Treasure on Home. Enter the metal, item weight, quantity, purity, and whether the weight is gross or fine. Purchase details and notes are optional. Reopen an item to edit it; deletion asks for confirmation.

02What are built-in and custom presets?

Built-in presets provide starting details for common coins and bars; Custom Bullion is the manual-entry option. You can also create, edit, and delete custom presets with your own specifications. Presets are reusable templates. Each holding you add is saved separately, so later preset changes do not change existing holdings.

03How do market prices work?

Treasure Log can request reference quotes for gold, silver, and platinum from Gold API. Quotes are cached on your device and may be unavailable or stale if a refresh fails. Gold API also provides a provisional Copper HG market reference. The app interprets it as USD per avoirdupois pound, but Gold API does not explicitly document the quote unit or underlying benchmark. It is not verified physical copper spot pricing. Including HG in collection valuations is optional and disabled by default. Manual Copper price overrides are supported and take precedence while set.

04Can I use my own price?

Yes. Set a manual price override from Prices. A manual override takes precedence for that metal until you remove it; removing it lets the app use an available cached market quote again.

05How do collection goals work?

Set one goal based on collection value or metal weight. Home shows progress from the app’s current holding and pricing data, with chest artwork reflecting progress. A value goal depends on available price references.

06How do I back up or restore my collection?

Use More → Backup & Restore to export a JSON file. The current native V3 backup includes holdings, goals, manual prices, custom presets, and Home preferences. Exported files are not encrypted by Treasure Log. Restore is replace-only and requires validation, a preview, and a final confirmation. Older native V2 and legacy web V1 files remain supported; because they do not contain custom presets, restoring one warns that your currently saved custom presets will be removed.

07Where is my collection stored?

Holdings, goals, manual price overrides, and custom presets are stored locally by the app on your device. Home display preferences are also stored locally. When prices refresh, the app makes network requests to Gold API for supported metals; those requests do not include your holdings in the app code.
